## What is Calculadora de Reticula Editorial?

Calculadora de Reticula Editorial is a browser-based, single-page tool that calculates and displays editorial grids as you work. Its interactive canvas makes it possible to examine page structure, spacing, and typographic relationships without leaving the page.

The project is intended for both learning and layout preparation. It helps users test paper formats, margins, columns, gutters, and baseline rhythm, while also providing conversion references between PostScript/DTP and Didot. This makes it useful for studying editorial composition and comparing grid decisions with InDesign-style measurements.

1. Clone or download the repository:
   - `git clone https://github.com/seanhallxon1186/reticula-editorial-web-app.git
2. Move into the project directory.
3. Open the main HTML file directly, or use a static web server for local development.

For example:

- `python -m http.server 8000`

After starting the server, visit `http://localhost:8000`.

## Using the Calculator

1. Select one of the available paper formats, or provide your own dimensions.
2. Set the margins, number of columns, and gutters for the layout under review.
3. Watch the grid respond immediately to each adjustment.
4. Turn canvas layers on or off to isolate the structural information you need.
5. Consult the typographic conversion references when comparing measurement systems for a text grid.
6. Use the resulting arrangement as a guide for editorial exercises, mockups, or layout planning.
